# Laravel Migration作成

以下の要件に基づいてMigrationを作成してください。

【要件】
ここにテーブル要件を記述する。

実装前に既存のMigrationとModelを確認してください。

以下を確認してください。

- 既存テーブルとの関係
- 外部キー
- nullable
- default
- unique
- index
- cascade設定

既存データへの影響を考慮してください。

Migrationだけでなく、必要に応じて以下の変更も提案してください。

- Model
- Factory
- Seeder
- FormRequest
- Filament Resource

既存のMigrationを不用意に変更せず、新しいMigrationを作成する方針を優先してください。
