# Filament Resource作成

以下のModelに対応するFilament Resourceを作成または変更してください。

【Model】
ここにModel名を記述する。

最初に以下を確認してください。

- Model
- Migration
- Fillable
- Cast
- Relation
- Filamentのバージョン
- 既存Resourceの構造

Formでは、DBカラムと入力項目の整合性を確認してください。

Tableでは、一覧表示に必要な項目だけを表示してください。

以下を必要に応じて実装してください。

- Form
- Table
- Filters
- Actions
- BulkActions
- RelationManagers

既存プロジェクトのFilamentの書き方を優先してください。

Filamentのバージョンに存在しないAPIを使用しないでください。

実装後に、以下を確認してください。

- Class名
- Namespace
- Modelとの一致
- DBカラムとの一致
- Formフィールド名
- Tableフィールド名
- Relationの定義
- Route
