# Laravelコードレビュー

現在のコードをレビューしてください。

以下の観点で確認してください。

## 正確性

- 要件通りに動作するか
- 条件分岐に漏れがないか
- null処理が適切か

## Laravel

- Laravelの標準機能を活用できているか
- Controllerに責務が集中していないか
- Eloquentの使い方が適切か
- N+1問題がないか

## DB

- 不要なクエリがないか
- トランザクションが必要ではないか
- インデックスが必要ではないか

## セキュリティ

- 入力値検証
- 認証
- 認可
- SQLインジェクション
- XSS
- Mass Assignment
- ファイルアップロード

## 保守性

- 可読性
- 重複コード
- 命名
- 責務分離
- 将来的な拡張性

問題を以下の重要度で分類してください。

- Critical
- High
- Medium
- Low

問題がない項目については、無理に問題を作らないでください。
