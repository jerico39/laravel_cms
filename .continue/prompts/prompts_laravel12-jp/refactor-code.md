# Laravelリファクタリング

現在のコードをリファクタリングしてください。

ただし、動作を変更しないことを最優先とします。

以下の観点で改善してください。

- 重複コード
- 長すぎるメソッド
- 複雑な条件分岐
- Controllerへの責務集中
- 不要なDBクエリ
- N+1問題
- 命名
- 型指定
- null処理

以下の原則を守ってください。

1. 変更範囲を最小限にする
2. 外部仕様を変更しない
3. DB構造を不用意に変更しない
4. APIレスポンスを変更しない
5. 既存の命名規則を維持する

変更前後の違いと、動作に影響がない理由を説明してください。
