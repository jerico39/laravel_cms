# PHP コーディングルール

## PHPバージョン

プロジェクトのcomposer.jsonで指定されたPHPバージョンを優先する。

PHPバージョンに存在しない構文や機能を使用しない。

## 型

可能な限り以下を明示する。

- 引数の型
- 戻り値の型
- プロパティの型

## null処理

nullの可能性がある値を無視しない。

## 可読性

1つのメソッドに多くの責務を持たせない。

深いネストを避ける。

条件分岐が複雑になった場合は、privateメソッドへの分割、Serviceへの分離、Value Object、Enumなどを検討する。

## マジックナンバー

意味のある数値や文字列は、可能であれば定数またはEnumにする。

## 既存コードとの互換性

既存プロジェクトが古いPHP記法を使用している場合、無理に全体を最新構文へ変更しない。

今回の変更に必要な範囲だけを変更する。
