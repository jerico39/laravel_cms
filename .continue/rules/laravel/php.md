# PHP Rules

## Version

Use PHP 8.4+ syntax.

---

## Coding Style

- Follow PSR-12.
- Use strict typing.
- Use constructor property promotion.
- Use readonly where appropriate.
- Prefer dependency injection.
- Always declare return types.
- Prefer typed properties.
- Prefer enums over constants.
- Prefer match over switch when suitable.

---

## Good Practices

- Avoid static state.
- Avoid global helpers unless Laravel convention.
- Keep methods small.
- Prefer composition over inheritance.
- Prefer immutable objects.
